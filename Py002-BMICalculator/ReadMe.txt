# ⚖️ BMI Calculator
A beginner-friendly Python program that calculates Body Mass Index (BMI) using the user's height and weight.

## ✨ Features
- Accepts height in meters.
- Accepts weight in kilograms.
- Calculates BMI using the standard formula.
- Categorizes BMI into underweight, healthy, and overweight ranges.

## 🧮 BMI Formula
BMI is calculated using the following formula:
```text
BMI = Weight (kg) / Height (m)²
```

## 📊 BMI Categories
| BMI Range | Category |
|---|---|
| Below 18.5 | Underweight |
| 18.5 – 25 | Healthy range |
| Above 25 | Overweight |

These are simplified adult BMI categories, not a medical diagnosis.

## 🛠️ Requirements
- Python 3.x
- No external libraries required.

## 🚀 How to Run
Execute the following command from the project directory:
```bash
python main.py
```
