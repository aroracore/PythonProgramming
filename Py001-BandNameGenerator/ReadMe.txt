# 🎸 Band Name Generator
A simple beginner-friendly Python program that generates a creative band name using your pet's name and birth city.

## ✨ Features
- Accepts the user's pet name.
- Accepts the user's birth city.
- Combines both inputs to generate a personalized band name.

## 🛠️ Requirements
- Python 3.x
- No external libraries required.

## 🚀 How to Run
Clone the repository, navigate to its directory, and execute:
```bash
python main.py
```

## 💻 Example Output
```text
Welcome to the Band Name Generator!
Enter your pet's name: Bruno
Enter your birth city's name: Delhi
Your band name could be Delhi Bruno!
```

- `print()` function
- `input()` function
- Variables
